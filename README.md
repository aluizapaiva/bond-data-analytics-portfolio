# Data Analytics Portfolio

Ana Paiva

Selected projects from my postgraduate Data Analytics coursework at Bond University. Each folder is one unit, with the code, the written report, and a short README explaining the problem, the method and the result.

## Projects

| Folder | Unit | What it shows | Tools |
|---|---|---|---|
| [01-capstone-windbreaker](01-capstone-windbreaker) | DTSC71-304 Applied Data Analytics Project | Capstone with a real agency partner: an XGBoost recommendation and alerting engine for Meta advertising campaigns across five clients | Python, pandas, XGBoost, scikit-learn, Google Colab |
| [02-marketing-analytics](02-marketing-analytics) | MKTG71-315 Marketing Analytics | Marketing mix models, marketing experiments and topic modelling, written up as a replication report | R |
| [03-multivariate-research-methods](03-multivariate-research-methods) | PSYC71-409 Multivariate Research Methods | Scale validation (EFA, reliability) and hierarchical regression on survey data from 377 participants | SPSS syntax |
| [04-data-science-and-programming](04-data-science-and-programming) | DTSC71-100 and DTSC71-200 | Population and stock analysis, KNN and clustering, and classification models for income prediction | Python, R, Power BI |
| [05-statistical-learning-and-regression](05-statistical-learning-and-regression) | DTSC71-302 Statistical Learning and Regression Models | Mixed-effects modelling of bird recovery after the 2019-20 Australian bushfires | R, lme4, mgcv |
| [06-deep-learning](06-deep-learning) | DTSC301 Deep Learning | Neural network for a bank campaign, CNN for skin lesion classification, and fraud detection in job listings (each published as its own repository, linked from the folder) | Python, TensorFlow and Keras |
| [07-modern-machine-learning](07-modern-machine-learning) | DTSC71-306 Modern Machine Learning Models | Unsupervised clustering for timber species identification, and an interactive dashboard on UN migration data | Python, scikit-learn, Plotly |

## Notes

- **No datasets are included.** Course datasets, survey responses and client data are not mine to redistribute. Each README names the data source so the work can be reproduced where the data is public.
- **The capstone is anonymised.** Client names are replaced with Client A to E, and notebook outputs are cleared because they contained client results.
- **Only my own work is here.** Lecturer solutions, slides, exam papers and course-supplied code are left out.
