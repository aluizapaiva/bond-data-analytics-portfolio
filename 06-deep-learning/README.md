# Deep Learning

**Unit:** DTSC301 Deep Learning
**Tools:** Python, TensorFlow and Keras, scikit-learn, Google Colab

Three projects, each framed as a business problem with a technical notebook and a management report. Each one lives in its own repository, with a README covering the business context, approach and results.

| Project | Repository | What it shows |
|---|---|---|
| Term deposit campaign | [DeepLearning_A1](https://github.com/aluizapaiva/DeepLearning_A1) | A feedforward neural network that predicts which bank customers will subscribe to a new term deposit. 45,211 customers and 17 features. |
| Skin lesion CNN | [DeepLearning_A2](https://github.com/aluizapaiva/DeepLearning_A2) | A convolutional neural network for a hospital dermatology department, classifying ISIC dermoscopic images as benign or malignant, with a focus on recall. |
| Job listing fraud | [DeepLearning_A3](https://github.com/aluizapaiva/DeepLearning_A3) | Fraud detection for a job board, comparing a model on company details, a text model and a combined model. |
