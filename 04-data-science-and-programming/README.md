# Data Science and Programming

**Units:** DTSC71-100 Business Analytics Coding, DTSC71-200 Data Science

## population-and-stock-analysis-python

Python project with two parts. Part 1 loads UN World Population Prospects data into pandas, builds a country-level table and checks whether net migration balances to zero across countries. Part 2 builds reusable functions and analyses correlations between stock closing prices.

- `analysis.ipynb`: notebook with code, outputs and written interpretation.

## bank-marketing-analysis

Classification and clustering analysis (KNN and clustering) in R Markdown. One parameterised `.Rmd` produces two reports: a technical report with the full code and a management report with the findings for a non-technical reader.

- `Bank_Analysis.Rmd`: source.
- `Technical_Report.pdf` and `Management_Report.pdf`: the two outputs.

## census-income-models

Four models built in R and visualised in Power BI, using census data to predict whether income is above 50K: decision tree, logistic regression and KNN, plus a k-means clustering of the same population.

| Model | Accuracy | Precision | Recall |
|---|---|---|---|
| Decision tree | 83.8% | 77.4% | 50.2% |
| Logistic regression | 83.8% | 72.3% | 57.2% |
| KNN | 81.1% | 69.2% | 44.6% |
| K-means clustering | 75.4% | n/a | n/a |
