# Multivariate Research Methods

**Unit:** PSYC71-409 Multivariate Research Methods
**Tools:** SPSS syntax

## Validity and Reliability of The Feelings Scale

SPSS analysis of the psychometric properties of a 32-item self-report scale, and of whether demographics predict its subscales, using a community sample of 377 participants.

Key results:

- Exploratory factor analysis (principal axis factoring, direct oblimin rotation) gave a three-factor solution: Wellbeing, Health and Resilience.
- The three factors explained 33.21% of the variance.

## SPSS syntax

The `spss-syntax` folder holds the analysis in the order I ran it.

| File | Step |
|---|---|
| `01_efa.sps` | Final 3-factor exploratory factor analysis |
| `02_composite_scores.sps` | Item retention decisions and subscale composite scores |
| `03_hierarchical_regression.sps` | Hierarchical multiple regression in five blocks |
| `04_crosstab_demographics.sps` | Gender by age group cross-tabulation for the participants section |
