# Marketing Analytics

**Unit:** MKTG71-315 Marketing Analytics
**Tools:** R

## Replication report: all resources are limited

`Replication_Report.docx` is my written report. It replicates and explains three analyses from the course text:

- **Marketing mix models:** an OLS regression framework for estimating how marketing spend drives sales.
- **Marketing experiments:** causal estimation with propensity score matching.
- **Unstructured data analysis:** structural topic modelling on customer reviews.

For each one the report explains the method, interprets the output and states the marketing decision it supports.

The R scripts and datasets for these replications come with the course, so they are not included here. Only my own write-up is.
